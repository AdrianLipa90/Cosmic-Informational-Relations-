# CIR Claim Status

CIR uses the TIR claim hierarchy.

| Class | Meaning |
|---|---|
| A | Established mathematical identity or externally sourced experimental fact. |
| B | TIR/CIR structural law or internally derived consequence with explicit premises. |
| C | Retrospective phenomenological assignment developed with access to target values. |
| D | Diagnostic, retained failure, falsification witness, or restricted no-go result. |
| E | Prospectively frozen prediction with declared observable and no-refit rule. |
| F | External scale, convention, measured anchor, or conversion input. |
